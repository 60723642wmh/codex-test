# 广州黄埔海事处辖区智慧地图

给新入职同事用的交互式辖区图。用浏览器打开 `index.html` 就能看（需要联网加载地图库 Leaflet 和字体）。

- `map.jpg`：用展板《广州黄埔海事处辖区示意图》照片做透视校正后得到的底图（1800×1118 像素）
- `index.html`：页面本体。要素、辖区特点和导览内容都写在页面底部脚本开头的 `FEATURES` / `TRAITS` / `TOUR` 三个数组里

## 新增或修改要素

在 `FEATURES` 里照已有条目复制一行，改 `name`、`cat`（类别）、`x`/`y`（在 map.jpg 上的像素坐标，左上角为 0,0）、`desc`（说明）和 `src`（资料来源）。

本示意图不能代替海图，不能用于航行。
